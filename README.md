# Rejus Zuzevicius

**Cybersecurity and digital forensics student at TU Dublin. Lithuanian, based in Dublin.**

I write code because I'd be doing it anyway, degree or not — security is just
the part I kept reading about until it became the course. Most of what I build
started as something I wanted to exist and couldn't find: a study app that
didn't want an account, a rostering tool for a factory floor that wasn't a
spreadsheet. The forensics side keeps dragging the rest of it back to the same
question — what is this thing doing with my data while I'm not looking?

## Selected work

**[Tomoru](https://github.com/RejusZuizo/Tomoru)** — a calm, late-night study
companion. Pomodoro, timetable, grades, flashcards and a focus journal in one
local-first desktop app. No account, no sync, no telemetry — everything is one
JSON file on your own machine, and it works with the wifi off. C# / .NET.

**[toolbox](https://github.com/RejusZuizo/toolbox)** — the smaller things. A
hash identifier, scripts, one-sitting tools. Anything that doesn't earn its own
repo lives here, each with a note on what it does and what I learned building
it.

**LineWise** — production line rostering for food manufacturing. Windows
desktop, .NET 8. Private repo, happy to talk about it.
